# AgentKnife

A desktop IDE where an AI agent builds apps for people who don't write code. Describe what you want in chat, watch it appear in a live preview, and get an installer at the end.

- Product spec (zh-TW): [docs/SPEC.md](docs/SPEC.md)
- Rules for contributors and AI agents: [AGENTS.md](AGENTS.md)
- Progress: [plan/STATUS.md](plan/STATUS.md)

Status: early development (Phase 1 / MVP). Nothing usable yet.
